# 💰 Expense Tracker Dashboard (React)

A modern **full-stack style frontend finance tracker** built using React.  
It includes **login system, income & expense tracking, charts, filters, and local storage per user**.

---

# 🚀 Features

## 🔐 Authentication System
- User Signup
- User Login
- Logout
- Data stored per user using localStorage

---

## 💰 Finance Features
- Add Income
- Add Expense
- Separate Income & Expense tracking
- Auto balance calculation

---

## 📊 Dashboard
- Total Income
- Total Expense
- Remaining Balance
- Real-time updates

---

## 📅 Filters
- Filter by Month
- Filter by Category
- Combined income + expense categories

---

## 📈 Charts
- Pie chart for expense breakdown
- Category-wise visualization
- Auto color mapping

---

## 💾 Storage
- Uses browser localStorage
- Each user has separate data:

# 🛠️ Tech Stack

- React.js ⚛️
- Chart.js 📊
